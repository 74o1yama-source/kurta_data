
エンジフェア デジタルマップ 完全配布用ZIP

このZIPには以下のファイルが含まれています：
- index.html
- app.js（修正版）
- sw.js（Service Worker 修正版）
- booths.json
- routes.json

※ map.webp（会場マップ画像）, styles.css, manifest.webmanifest は
  この実行環境に存在しないため含まれていません。
  既存のものを同じフォルダに配置してください。

配置後、そのまま GitHub Pages / Webサーバにアップロードすれば
オフライン対応PWAとして動作します。
